# 数据库配置说明

## 错误提示

如果启动服务器时看到以下错误：
```
Unhandled rejection SequelizeConnectionError: Unknown database 'shopping_weixin'
```

说明数据库 `shopping_weixin` 不存在，需要先创建数据库。

## 解决方案

### 方法一：使用 MySQL 命令行创建（推荐）

1. **打开 MySQL 命令行**或使用 MySQL 客户端工具（如 Navicat、phpMyAdmin、MySQL Workbench）

2. **登录 MySQL**：
   ```sql
   mysql -u root -p
   ```
   输入密码：`12345`

3. **创建数据库**：
   ```sql
   CREATE DATABASE IF NOT EXISTS `shopping_weixin` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

4. **验证数据库是否创建成功**：
   ```sql
   SHOW DATABASES;
   ```
   应该能看到 `shopping_weixin` 数据库

5. **退出 MySQL**：
   ```sql
   exit;
   ```

6. **重新启动服务器**：
   ```bash
   node index.js
   ```

### 方法二：使用 SQL 文件

1. 使用 MySQL 客户端工具打开 `创建数据库.sql` 文件

2. 执行 SQL 语句创建数据库

3. 重新启动服务器

## 数据库配置

当前数据库配置（在 `config/config.js` 中）：
- **数据库名**：`shopping_weixin`
- **用户名**：`root`
- **密码**：`12345`
- **主机**：`localhost`

如果您的 MySQL 配置不同，请修改 `config/config.js` 文件中的 `mysqlOptions` 配置。

## 表结构说明

数据库表结构会由 Sequelize ORM 自动创建，包括：
- `user` - 用户表
- `product` - 商品表
- `type` - 商品类型表
- `shopcart` - 购物车表
- `like` - 收藏表
- `order` - 订单表
- `address` - 地址表
- 等等...

**注意**：Sequelize 配置为 `force: false`，不会覆盖已存在的表，只会创建不存在的表。

## 验证数据库连接

创建数据库后，重新启动服务器，如果看到：
```
the server running on http://127.0.0.1:7001
```
且没有数据库错误，说明连接成功。
